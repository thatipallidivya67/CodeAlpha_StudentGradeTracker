# CodeAlpha_StudentGradeTracker
Student Grade Tracker  The Student Grade Tracker is a Java-based console application designed to manage student academic records and calculate their performance efficiently.  The application allows users to add student names and marks, store student information using ArrayLists, and display individual student records. It automatically calculates the average marks, identifies the highest and lowest scores, and assigns grades based on students' marks.  The project is developed using Java programming concepts such as Object-Oriented Programming (OOP), classes, objects, ArrayLists, loops, conditional statements, and methods.  **Key Features:** - Add and manage student records. - Store student names and marks. - Calculate average marks. - Identify the highest and lowest scores. - Assign grades based on marks. - Generate a student performance summary.  **Technologies Used:** Java, VS Code.  **Project Type:** Console-Based Application.  **Objective:** To simplify student grade management while demonstrating fundamental Java programming and problem-solving skills.
